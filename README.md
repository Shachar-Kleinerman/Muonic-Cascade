# Muonic-atom cascade and X-ray spectrum simulator

Streamlit front end for the MUDIRAC Dirac-equation solver (STFC, MIT licence - see `LICENSE-MUDIRAC.txt`).
All transition energies and rates come from MUDIRAC; nuclear data from NUBASE2020 (IAEA).

Run locally (Linux / WSL):

    pip install -r requirements.txt
    streamlit run app.py
